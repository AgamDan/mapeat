## Conventions

- Read the design spec before implementing any feature. Proposals in it are not approved until confirmed.
- New research goes in `research/` as `YYYY-MM-DD-topic.md`.
- Update `status/handoff.md` whenever project status, environment, or blockers change.
- Agent and contributor rules live outside `docs/`: [AGENTS.md](../AGENTS.md) and [.github/copilot-instructions.md](../.github/copilot-instructions.md).
